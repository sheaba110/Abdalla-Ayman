01 About

My journey into software engineering started with a simple curiosity: how can an idea become something that actually works? What began with learning how to write code gradually became an interest in understanding how complete systems are designed, built, and made reliable.

As I built more projects, I found myself drawn toward backend engineering working with APIs, databases, automation, and the logic that connects everything together. Along the way, I’ve worked with Python, Django, Django REST Framework, PostgreSQL, Docker, and Java, while taking on freelance work and building solutions around real-world problems.

Today, I enjoy taking complicated requirements and turning them into clean, practical software. I’m still learning, still building, and still curious about what’s possible because for me, software engineering isn’t just about writing code. It’s about building things that matter.

03 Work

Two projects I've spent the most time inside.

MarketLens source ↗

An aggregation platform that pulls product data from multiple Egyptian e-commerce sites into one searchable place. The scraping layer runs on Scrapy and Playwright; search is handled by Meilisearch across 10,000+ products with sub-100ms response times. Backend is Django REST Framework, frontend is Next.js with React InstantSearch.
